# n2 — modules lifted, zero InFlow dependency

Ten modules: envelope, allowance, credential, intent, ledger, store, enforcement, gate, storage,
index. Gate: all present and `grep -ril inflow src/` returns nothing.

Only gate.ts needed rewriting. It imported our own classes through @inflowpayai/inflow-core
because that is where they happened to live; now it imports siblings.

storage.ts is new and replaces the tables we had bolted onto InFlow's sqlite.ts. Purser owns the
schema outright: principals, principal_allowance, agents, intents, agent_ledger, used_nonces,
clock_state. node:sqlite is loaded via createRequire because a static import of a runtime built-in
fails under several bundlers, which is the same reason InFlow does it.

flows.ts was deliberately left behind. It projected AgentView for the InFlow CLI's output
contract, and Purser has no such contract yet.
