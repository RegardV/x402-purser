# n2 - the signer policy validator

`src/signer/validate.ts`: `SignerPolicy`, `SignerRefusedError`, `validateSigningRequest`. Pure, no
IO, so every refusal path is directly testable.

Checks, in order: primaryType is TransferWithAuthorization, types holds exactly that one entry with
the six EIP-3009 fields in order, chainId is allowlisted, verifyingContract is allowlisted, `from`
is our own address, value is a bigint at or under the signer ceiling, validAfter is a bigint, and
validBefore is in the future and inside the horizon.

11 tests. The load bearing ones are `not_a_payment` (a Permit shaped payload is refused, which is
what stops a compromised daemon getting a transaction signed) and `unexpected_types` (a tampered
field type changes what the signature commits to while the message still looks normal).
